Data is live from the Support SLA Monitor API (/tickets). Compliance is measured against each ticket's own SLA deadline: urgent gets a first reply in 4h and a resolution in 24h, high 12h / 48h, normal 24h / 72h. Tickets are triaged by the API, logged to a Google Sheet, and urgent ones alert Slack. Demo data is synthetic, for the fictional brand Zuri Fragrances.
